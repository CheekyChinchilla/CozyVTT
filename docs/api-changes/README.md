# API changes, release by release

What a program driving CozyVTT may notice from one release to the next: routes, live-table events, fields, status codes, limits and messages. The HTTP routes and live-table events are not a versioned public API, but programs do drive them with a signed-in account (see [API Reference](../API_REFERENCE.md)).
